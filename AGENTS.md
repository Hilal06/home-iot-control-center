# Project Guidelines & Agent Instructions

This project uses **Ponytail** (Lazy Senior Dev Mode) and **Impeccable** (Design Excellence).

## Ponytail Rules (Anti-Overengineering)
- **The best code is the code never written.** Solve the whole problem with the least new code.
- **YAGNI (You Aren't Gonna Need It):** Skip features, wrappers, options, and abstractions nobody asked for.
- **Standard Library / Built-in First:** Prefer built-in language features or existing codebase patterns over pulling heavy external dependencies.
- **Minimal Working Diff:** The shortest, cleanest working change that fully handles the task, edge cases, and callers.
- **No Buzzwords & Direct Dev-ish Communication:** Keep explanations concise, direct, and actionable without fluff or AI slop.

## Impeccable Rules (UI & Frontend Quality)
- Strict rectilinear 0px corners (`border-radius: 0`).
- Industrial SCADA theme (Dark slate, amber accents, clear telemetry monospace digits).
- High contrast, responsive, no purple AI slop.
